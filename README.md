# Cloud Cost Comparison: AWS vs Azure

## Overview

This repository contains a comparative cost analysis of hosting a small web application on Amazon Web Services (AWS) and Microsoft Azure.

The comparison includes:

- AWS Pricing Calculator estimate
- Azure Pricing Calculator estimate
- Cost breakdown reports
- Provider comparison
- Business recommendation
- Pricing calculator screenshots

## Application Specifications

- Application Type: Small Web Application
- CPU: 2 vCPUs
- RAM: 4 GB
- Storage: 100 GB SSD
- Monthly Data Transfer: 500 GB
